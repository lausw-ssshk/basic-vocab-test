Teacher notes

Scoring, warm-up, and adaptive rules (for teachers).

About this tool

Closest Meaning Test. Estimates mastery of high-frequency English (Oxford 3000–style bands) as one number from 0 to 3000. Classroom use only. Students only see the final score — band details stay in this teacher-facing note.

Item format

Every item shows a situational sentence with one underlined target word. Choose the option with the closest meaning (4 structure-matched choices). Hear the sentence and each option when speech is available.

Opening block

  • Every sitting starts with 8 very easy Band-1 items (closest meaning). They count in the score.

Band moves (every block of 8, including opening)

  • ≥7/8 correct → jump +2 bands
  • ≥75% but <7/8 (i.e. 6/8) → +1
  • 40–74% → stay
  • <40% → −1

Stopping & final probe

  • Do not stop for precision while still climbing (last move up, or ≥75% on highest band with room above).
  • Soft aim ~12–15 min and soft item cap ~90 if not climbing; hard caps 20 min / ~100 items.
  • Before ending (non-hard), if highest visited band rate ≥75%, run one real probe block at the next higher band (if any), then end.

Scoring / imputation

  • Visited bands → empirical rate. Easier unvisited → 1.0.
  • Skipped mid bands (e.g. after +2 jump): treated as mastered (1.0) if surrounded by strong (≥75%) results; otherwise interpolate.
  • Bands above the last real high-band probe only: mild decay (×0.85 per step). If top rate <40%, harder unvisited → 0.
  • Estimate = Σ (rate × 500), rounded, 0–3000.

The running estimate is hidden until the end. Students show the single /3000 score on screen — nothing is uploaded.
